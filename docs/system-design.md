# 智能学习 Agent 系统设计说明

## 1. 项目定位

本项目定位为个人学习者版高校课程个性化学习资源多智能体生成平台。系统围绕高校课程学习场景，结合大模型、RAG、多智能体协作、学习画像和多模态资源生成能力，为学生提供课程问答、个性化资源包、错题复盘、学习报告和学习路径推荐。

## 2. 业务痛点

- 高校课程资源分散，学生难以快速筛选适合自身水平的学习材料。
- 传统教学资源缺少个性化适配，无法根据学习基础、认知偏好和薄弱点动态调整。
- 通用大模型容易产生无依据回答，需要课程资料引用、防幻觉校验和内容安全机制。
- 学习过程缺少闭环，提问、练习、错题、资源推荐、学习报告之间割裂。
- 多模态资源生成耗时较长，需要明确的生成过程追踪和状态反馈。

## 3. 总体架构

系统采用前后端分离架构：

- 前端：`frontend-demo`，提供学习工作台、会话中心、资源生成、资源中心、错题本、学习报告、画像中心等页面。
- 后端：`backend`，基于 FastAPI，提供认证、课程、RAG 问答、资源生成、学习画像、掌握度、报告、资源下载等接口。
- 数据库：默认 SQLite，预留 PostgreSQL 扩展。
- 知识库：ChromaDB，存储课程资料切片和向量索引。
- LLM Provider：支持 DeepSeek、科大讯飞 Spark 和 mock/fallback。
- 资源存储：默认本地目录 `data/generated`，预留 S3/MinIO 扩展。

## 4. 核心模块

### 4.1 学习工作台

首页展示当前课程、课程进度、错题数、收藏数、学习闭环流程卡、画像摘要、最近资源包和今日推荐。

### 4.2 对话式学习助手

支持课程资料 RAG 问答，并展示：

- 引用来源
- grounding 分数
- 风险等级
- 内容安全状态
- 无依据提示
- 多智能体协作过程
- 个性化资源包

### 4.3 多智能体协作

标准智能体链路包括：

- Planner / TutorAgent：拆解学习任务
- ProfileAgent：识别学习画像
- Retriever / InformerAgent：检索课程资料
- Generator / LectureAgent：生成带引用回答或资源
- VerifierAgent：校验回答质量和引用支撑
- ResourceBuilder / PracticeAgent：构建资源建议和资源包

每条 trace 统一包含：

- `agent`
- `phase`
- `status`
- `summary`
- `latency_ms`
- `output`
- `timestamp`

### 4.4 RAG 防幻觉

系统通过课程资料检索、引用来源、grounding 评分、unsupported claims 和内容安全检测降低幻觉风险。问答结果不会只展示模型答案，还会展示可信依据和风险提示。

### 4.5 学习画像

系统根据对话、行为和测验持续更新学习画像，包括：

- 知识基础
- 学习目标
- 认知风格
- 薄弱点
- 内容偏好
- 学习节奏
- 情绪/信心线索

### 4.6 个性化资源包

围绕学习主题生成并聚合多类型资源：

- 讲义
- 思维导图
- 练习题
- PPT
- 拓展阅读
- 视频脚本
- 学习路径

资源包包含资源项、智能体数量、grounding 分数、安全状态和推荐摘要。

### 4.7 学习效果评价

通过 quiz submit、错题本和知识点掌握度模型形成学习效果闭环。学习报告展示：

- 测验正确率
- 错题数
- 收藏数
- 平均掌握度
- 单知识点掌握度条
- 强项 / 弱项
- 推荐动作

## 5. 数据流

1. 学生选择课程并提问。
2. 系统读取课程知识库，检索相关资料片段。
3. 多智能体根据问题、画像和资料生成回答。
4. Verifier 校验引用支撑和回答质量。
5. 前端展示回答、引用、防幻觉卡片和智能体 trace。
6. 系统推荐并生成个性化资源包。
7. 学生完成练习题后，系统更新错题本和掌握度。
8. 学习报告根据掌握度、错题和行为给出下一步建议。

## 6. 安全与配置

- LLM 密钥仅管理员可配置。
- `.env.example` 提供配置模板，不包含真实密钥。
- 非法资源下载路径会被拦截。
- demo endpoint 已禁用，避免比赛环境误用假数据。
- smoke 脚本覆盖权限、资源、报告、掌握度和问答可信字段。
