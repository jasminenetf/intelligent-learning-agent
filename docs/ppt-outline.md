# 答辩 PPT 大纲

## 1. 封面

- 项目名称：高校课程个性化学习资源多智能体生成平台
- 副标题：面向个人学习者的可信问答、资源包生成与学习效果闭环系统
- 团队 / 成员 / 日期

## 2. 背景与痛点

- 高校课程资源分散，学生筛选成本高。
- 不同学生基础、目标、偏好和薄弱点差异明显。
- 通用大模型回答缺少课程依据，存在幻觉风险。
- 传统学习系统缺少“提问 - 资源 - 测验 - 错题 - 报告 - 路径”的闭环。

## 3. 项目定位

本系统定位为：

> 高校课程个性化学习资源多智能体生成平台。

核心能力：

- 对话式学习画像
- 基于课程资料的可信 RAG 问答
- 多智能体协同生成资源包
- 多模态学习资源展示
- 错题复盘和掌握度评价
- 个性化学习路径推荐

## 4. 总体架构

建议配图：前端、后端、数据库、知识库、LLM Provider、资源存储。

- 前端：学习工作台、问答、资源中心、错题本、学习报告、画像中心
- 后端：FastAPI 服务层
- 知识库：ChromaDB 课程切片检索
- 编排：LangGraph 多智能体流程
- 模型：DeepSeek / Spark / fallback
- 数据：SQLite 快速模式，预留 PostgreSQL 扩展

## 5. 多智能体协作流程

智能体链路：

1. Planner / TutorAgent：拆解问题和学习任务
2. ProfileAgent：识别学生画像
3. Retriever / InformerAgent：检索课程资料
4. Generator / LectureAgent：生成回答或资源
5. VerifierAgent：校验引用和可信度
6. ResourceBuilder / PracticeAgent：聚合资源包和学习建议

Trace 标准字段：

- agent
- phase
- status
- summary
- latency_ms
- output
- timestamp

## 6. RAG 防幻觉机制

- 基于课程资料切片检索回答问题
- 显示引用来源和页码/片段信息
- grounding_score 量化引用支撑
- risk_level 标注风险等级
- content_safety 检查内容安全
- unsupported_claims 提示无依据内容

## 7. 个性化学习画像

画像维度：

- 知识基础
- 学习目标
- 认知风格
- 内容偏好
- 薄弱点
- 学习节奏
- 学习历史
- 情绪/信心状态

画像用途：

- 调整回答深度
- 推荐资源类型
- 生成学习路径
- 指导错题复盘

## 8. 个性化资源包

资源包内容：

- 讲义
- 思维导图
- 练习题
- PPT
- 拓展阅读
- 视频脚本
- 学习路径

展示信息：

- 主题
- 资源数量
- 智能体数量
- grounding 分数
- 安全状态
- 推荐学习顺序
- 适配画像说明

## 9. 学习效果评价

系统通过测验、错题和行为记录构建掌握度模型：

- 平均掌握度
- 知识点掌握度条
- 正确率趋势
- 掌握度分布
- 错题知识点分布
- 本周学习摘要
- 下一步推荐动作

## 10. 系统演示流程

1. 打开首页工作台
2. 查看当前课程和学习闭环
3. 进入画像中心查看六维画像
4. 在问答页提问课程问题
5. 查看引用、防幻觉和多智能体 trace
6. 查看资源包详情
7. 生成讲义、导图、题库、PPT 或视频脚本
8. 完成一道练习题
9. 查看错题本和掌握度变化
10. 打开学习报告查看趋势和建议

## 11. 创新点

- 将 RAG、防幻觉、多智能体和学习画像结合到课程学习场景。
- 资源包不是单一文档，而是多模态、可复盘、可评价的学习资源组合。
- 学习过程形成闭环：问答、资源、测验、错题、报告、路径持续联动。
- 提供 smoke 回归脚本，保证核心链路稳定。

## 12. 工程实现与质量保障

- FastAPI + SQLModel + ChromaDB + LangGraph
- 前端工作台式产品界面
- `.env.example` 配置模板
- `requirements.txt` 依赖补齐
- P0 smoke 覆盖核心接口
- lint 检查无错误

## 13. 总结

本项目面向高校课程学习场景，构建了从可信问答到个性化资源包、从测验复盘到学习效果评价的完整闭环，为学生提供可解释、可追踪、可持续优化的智能学习体验。
