# 7 分钟答辩演示脚本

演示定位：`高数上`课程智能助教，面向基础薄弱学生，把一次提问自动转化为个性化学习包。

## 0. 准备

启动：

```powershell
.\启动智能学习Agent.bat
```

浏览器打开：

```text
http://127.0.0.1:5173
```

演示前运行：

```powershell
python scripts/deep_qa_check.py
```

## 1. 开场，30 秒

讲解词：

> 我们的项目是面向中国软件杯 A3 赛题的高等教育个性化学习资源多智能体系统。当前版本聚焦《高等数学上册》，解决基础薄弱学生“听不懂、不会复盘、不知道下一步学什么”的问题。

强调：

- 不是普通聊天机器人。
- 核心是学习闭环：提问、检索、回答、资源、练习、错题、画像、路径。

## 2. 系统状态，40 秒

操作：

- 打开设置页或顶部状态。
- 展示 Spark / Mock 状态。

讲解词：

> 系统支持科大讯飞 Spark 作为主推理引擎。答辩和本地演示时，如果 Key 或网络不可用，系统会自动进入本地课程 fallback，不反复消耗额度。真实调用、fallback 状态和失败原因都会展示，避免黑盒演示。

## 3. 课程与知识库，40 秒

操作：

- 打开课程中心或右侧课程依据。
- 展示 `高数上.pdf`。

讲解词：

> 当前内置《高数上.pdf》作为课程知识库，覆盖函数与极限、导数与微分、不定积分、定积分、微分方程等章节。回答和资源生成都会绑定教材章节，并在右侧展示引用依据。

## 4. 核心提问，90 秒

操作：

在会话中心输入：

```text
我不懂函数极限，讲清定义、常见误区，并给一个例题
```

讲解词：

> 学生只需要自然语言提问，不需要填复杂表单。系统会先识别知识点“函数极限”，再定位到《高数上》的函数与极限章节，同时更新学习画像。

等待回答后展示：

- 回答内容
- 教材依据
- Agent 轨迹
- 六维画像摘要
- 资源包建议

讲解词：

> 右侧可以看到引用覆盖率、风险等级、内容安全和 Agent 轨迹。系统不是直接把模型回答给学生，而是经过 Tutor、Informer、Profile、Verifier 等角色协作，尽量减少幻觉。

## 5. 自动生成学习资源，90 秒

操作：

- 不再点击按钮，等待右侧资源自动生成。
- 依次点开 5 个 tab。

展示顺序：

1. 思维导图
2. 练习题
3. 讲义
4. 学习路径
5. PPT

讲解词：

> 提问完成后，系统会自动生成五类学习资源。思维导图默认不是难以缩放的大图，而是可读的知识树；讲义按“误区诊断、前置知识、直观解释、严格定义、例题拆解、常见错误、自测清单”组织；PPT 当前采用 Markdown 教学稿，保证可打开、可复制、可讲课。

## 6. 测验与错题闭环，70 秒

操作：

- 打开练习题。
- 故意选错一题。
- 点击提交。

讲解词：

> 选错后系统不会直接跳到错题本，而是在原地解释：为什么错、正确思路是什么、对应哪个知识点、下一步该看什么资源。之后才把错题写入错题本，并回流到学习画像。

展示：

- 原地解析
- 错题本新增
- 画像版本变化
- 学习路径可重新生成

## 7. 学习路径与画像，70 秒

操作：

- 打开学习路径 tab 或学习路径页面。
- 打开画像中心。

讲解词：

> 学习路径不是固定模板。它会根据最近提问、教材章节、画像版本和错题记录动态生成。每一步都包含学习原因、配套资源、预计时间、练习任务和检验标准。画像中心展示至少六个维度：知识基础、学习目标、认知风格、薄弱点、资源偏好、情绪信心，并显示证据来源和置信度。

## 8. 资源下载，40 秒

操作：

- 到资源中心。
- 下载 PPT 或讲义。
- 打开 `.md` 文件。

讲解词：

> 所有资源都能下载为稳定可打开的 Markdown 文件。文件里不仅有内容，还有教材定位、生成来源、fallback 状态、Verifier 结果和生成依据，方便学生复习，也方便评委检查系统可信链路。

## 9. 总结，40 秒

讲解词：

> 总结一下，我们完成了三个闭环：第一，教材知识库到可信回答的 RAG 闭环；第二，提问到五类个性化资源的多智能体生成闭环；第三，做题、错题、画像和学习路径的学习效果闭环。这个版本优先把《高数上》一门课做深，符合 A3 赛题对个性化、多模态、多智能体和防幻觉的要求。

## 时间分配

| 环节 | 时间 |
|---|---:|
| 开场与状态 | 1:10 |
| 课程知识库 | 0:40 |
| 核心提问 | 1:30 |
| 自动资源 | 1:30 |
| 测验错题 | 1:10 |
| 路径画像 | 1:10 |
| 下载总结 | 1:00 |

总计约 7 分钟。
