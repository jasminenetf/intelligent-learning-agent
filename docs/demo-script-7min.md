# 7 分钟演示脚本

## 演示目标

在 7 分钟内完整展示系统闭环：

> 首页工作台 → 学习画像 → 可信问答 → 多智能体 trace → 个性化资源包 → 多模态资源 → 测验 → 错题复盘 → 学习报告 → 学习路径推荐。

## 准备工作

- 后端启动：`python -m uvicorn app.demo_main:app --host 127.0.0.1 --port 8010 --reload`
- 前端访问：`http://127.0.0.1:5173`
- 准备一个学生账号。
- 准备一门已有课程：高等数学上册。
- 准备一个示例问题：

```text
我不懂函数极限，讲清定义、常见误区，并给一个例题。
```

## 时间安排

### 0:00 - 0:30 开场和项目定位

讲解要点：

- 本项目面向高校课程学习场景。
- 目标是解决学生资源筛选难、学习路径不清晰、通用大模型回答缺乏依据等问题。
- 系统定位为《高数上》课程智能助教，面向基础薄弱学生。

演示动作：

- 打开首页工作台。
- 指出首页中的学习闭环流程卡。

### 0:30 - 1:10 首页工作台

讲解要点：

- 首页聚合课程进度、错题、收藏、薄弱点、本周摘要和最近资源包。
- 学生可以从首页直接进入问答、资源生成、错题复盘和学习报告。

演示动作：

- 展示当前课程。
- 展示薄弱点提醒。
- 展示本周学习摘要。
- 点击“开始可信问答”。

### 1:10 - 1:50 学习画像中心

讲解要点：

- 系统通过对话、测验和学习行为构建动态学习画像。
- 画像包含知识基础、学习目标、认知风格、内容偏好、薄弱点、学习节奏、学习历史、情绪信心等维度。
- 画像会参与问答深度、资源推荐和学习路径规划。

演示动作：

- 打开画像中心。
- 展示六维画像卡片。
- 展示“画像如何参与生成”。

### 1:50 - 2:50 可信 RAG 问答

讲解要点：

- 学生提问后，系统不是直接调用大模型，而是先检索课程资料。
- 回答会展示引用来源、grounding 分数、风险等级和内容安全状态。
- 这样可以降低幻觉风险，提高答案可信度。

演示动作：

- 进入问答页。
- 输入示例问题。
- 展示回答内容。
- 展示右侧课程依据、防幻觉卡片。

### 2:50 - 3:30 多智能体协作过程

讲解要点：

- 系统采用多智能体协作流程。
- Planner 负责拆解任务。
- ProfileAgent 负责读取学习画像。
- Retriever 负责检索课程资料。
- Generator 负责生成回答和资源。
- Verifier 负责校验引用与安全。
- ResourceBuilder 负责聚合个性化资源包。

演示动作：

- 展示右侧“学习助手协作”区域。
- 指出 trace 中的 agent、phase、status、summary。

### 3:30 - 4:30 个性化资源包和多模态资源

讲解要点：

- 系统会根据问题、画像和课程资料推荐个性化资源包。
- 资源包包括讲义、可读知识树、练习题、学习路径和 Markdown 教学版 PPT。
- 每个资源包都有 grounding、安全状态和推荐学习顺序。

演示动作：

- 点击资源包“查看详情”。
- 展示资源包详情页。
- 展示提问后自动出现的讲义、导图、题库、学习路径和 Markdown PPT。
- 展示 Markdown PPT 中的讲稿、板书、例题、自测和错因提醒。

### 4:30 - 5:20 测验与错题复盘

讲解要点：

- 系统支持根据当前主题生成练习题。
- 学生提交答案后，系统会更新错题本和知识点掌握度。
- 错题本提供复习讲义、知识结构图、巩固练习和复习路径。

演示动作：

- 生成或打开练习题。
- 提交一道题。
- 原地查看详细错因讲解，再进入错题本。
- 展示掌握度条和推荐动作。

### 5:20 - 6:20 学习报告和学习效果评价

讲解要点：

- 学习报告从测验、错题、收藏和学习行为中综合评价学习效果。
- 展示完成率、正确率、平均掌握度、知识点掌握度、错题分布、资源使用和本周摘要。
- 系统会给出下一步推荐动作。

演示动作：

- 进入学习报告。
- 展示趋势图和掌握度分布。
- 展示薄弱知识点和画像驱动建议。

### 6:20 - 7:00 总结创新价值

讲解要点：

- 系统形成了完整闭环：

```text
课程资料 → 学习画像 → 可信问答 → 多智能体 trace → 个性化资源包 → 测验 → 错题 → 掌握度 → 学习报告 → 学习路径
```

- 创新点包括：
  - RAG 防幻觉与课程依据结合；
  - 多智能体协同生成学习资源；
  - 学习画像驱动个性化推荐；
  - 多模态资源包与学习效果评价闭环；
  - smoke + deep QA 回归保障核心功能稳定。

演示动作：

- 回到首页工作台。
- 指出学习闭环流程卡。
- 结束演示。

## 备用方案

如果资源生成较慢：

- 先展示已经生成的资源中心。
- 使用资源包详情页展示资源项。
- 使用 smoke 通过结果说明核心接口稳定。

如果课程资料为空：

- 展示 ask skip 的安全处理。
- 使用已有资源生成、画像、错题本和学习报告演示产品闭环。

如果 LLM Key 未配置：

- 展示 fallback / mock 结果。
- 重点讲架构、trace、grounding、安全和学习闭环。
