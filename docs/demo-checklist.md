# 演示 Checklist

## 1. 启动前检查

### 后端

- [ ] 已进入后端目录：`backend`
- [ ] 已安装依赖：`python -m pip install -r requirements.txt`
- [ ] 已确认 `.env` 或默认配置可用
- [ ] 已启动后端：

```bash
python -m uvicorn app.demo_main:app --host 127.0.0.1 --port 8010 --reload
```

- [ ] 健康检查可访问：`http://127.0.0.1:8010/health`

### 前端

- [ ] 已启动前端静态服务或本地预览
- [ ] 可访问前端页面：`http://127.0.0.1:5173`
- [ ] 浏览器控制台无明显报错

### Smoke

- [ ] 已运行 P0 smoke：

```bash
python scripts/verify_p0_smoke.py
```

- [ ] 已运行 deep QA：

```bash
python scripts/deep_qa_check.py
```

- [ ] 若后端使用临时端口，例如 `8010`：

```powershell
$env:P0_SMOKE_BASE='http://127.0.0.1:8010'
python scripts/verify_p0_smoke.py
```

- [ ] 结果为：`=== ALL CHECKS PASSED ===`

## 2. 账号与课程准备

- [ ] 已准备学生账号
- [ ] 已确认可登录
- [ ] 已选择或准备课程，例如：高等数学上册
- [ ] 课程中已有资料或可使用 fallback 演示
- [ ] 若课程资料为空，准备说明：系统会安全跳过无资料问答，并保留其他学习闭环演示

## 3. 推荐演示问题

主问题：

```text
我不懂函数极限，讲清定义、常见误区，并给一个例题。
```

备用问题：

```text
我对微积分基础薄弱，能不能用直观例子讲清函数极限？
```

```text
请根据我的错题知识点「函数极限」讲清楚定义、常见误区，并给一个例题。
```

```text
我准备期末复习，函数极限、连续和导数之间有什么关系？
```

## 4. 演示流程检查

### 4.1 首页工作台

- [ ] 展示项目定位：高校课程个性化学习资源多智能体生成平台
- [ ] 展示当前课程
- [ ] 展示学习闭环流程卡
- [ ] 展示课程进度、错题、收藏
- [ ] 展示薄弱点提醒
- [ ] 展示本周学习摘要
- [ ] 点击进入可信问答

### 4.2 学习画像中心

- [ ] 展示六维/八维画像卡片
- [ ] 展示画像如何参与问答、资源包和学习路径
- [ ] 展示画像版本或变更日志
- [ ] 可选：输入自然语言更新画像

### 4.3 可信 RAG 问答

- [ ] 输入推荐演示问题
- [ ] 展示回答内容
- [ ] 展示课程引用来源
- [ ] 展示 grounding 分数
- [ ] 展示 risk level
- [ ] 展示 content safety
- [ ] 展示无依据提示或安全说明

### 4.4 多智能体 Trace

- [ ] 展示学习助手协作面板
- [ ] 说明 Planner / Profile / Retriever / Generator / Verifier / ResourceBuilder
- [ ] 指出 trace 字段：agent、phase、status、summary、latency_ms

### 4.5 个性化资源包

- [ ] 展示资源包卡片
- [ ] 点击“查看详情”
- [ ] 展示资源包标题、主题、资源数量、智能体数量
- [ ] 展示 grounding、安全和风险状态
- [ ] 展示推荐学习顺序
- [ ] 展示画像适配和可信校验说明

### 4.6 多模态资源

至少展示其中 2 - 3 类：

- [ ] 讲义卡片
- [ ] 思维导图
- [ ] 练习题
- [ ] Markdown PPT 卡片或下载入口
- [ ] 拓展阅读
- [ ] 视频脚本分镜

### 4.7 测验与错题复盘

- [ ] 打开或生成练习题
- [ ] 提交一道题
- [ ] 原地查看详细错因讲解，再进入错题本
- [ ] 展示错题知识点
- [ ] 展示解析
- [ ] 展示掌握度条
- [ ] 展示推荐动作
- [ ] 展示复习讲义、巩固练习、知识结构图、复习路径入口

### 4.8 学习报告

- [ ] 展示完成率、错题数、收藏数、正确率、平均掌握度
- [ ] 展示学习效果趋势
- [ ] 展示掌握度分布
- [ ] 展示错题知识点分布
- [ ] 展示画像驱动建议
- [ ] 展示薄弱知识点和近期行为

### 4.9 总结

- [ ] 回到首页工作台
- [ ] 总结闭环：课程资料 → 画像 → 可信问答 → 多智能体 → 资源包 → 测验 → 错题 → 掌握度 → 报告 → 路径
- [ ] 强调创新点和工程质量保障

## 5. 备用方案

### 资源生成较慢

- [ ] 展示资源中心已有资源
- [ ] 展示资源包详情页
- [ ] 使用已生成内容演示多模态卡片

### 课程资料为空

- [ ] 说明系统不会编造课程依据
- [ ] 展示 ask skip 或无引用提示
- [ ] 继续演示画像、资源生成、错题本和学习报告

### LLM Key 未配置

- [ ] 使用 fallback / mock 结果
- [ ] 重点讲架构、trace、grounding、安全和学习闭环

### 网络或模型响应慢

- [ ] 跳过实时生成
- [ ] 使用资源中心、学习报告和系统设计文档继续讲解
